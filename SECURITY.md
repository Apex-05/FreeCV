# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's Private Vulnerability Reporting feature to report security issues privately.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any relevant screenshots, logs, or proof of concept

Please allow reasonable time for the issue to be investigated and addressed before publicly disclosing it.

## Scope

Security issues affecting the FreeCV application, its source code, dependencies, or deployment configuration can be reported through the private reporting channel.

For general bugs or feature requests, please open a GitHub issue instead.
